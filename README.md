# NodeJS Labs

This repository contains a complete set of Node.js lab exercises completed during the course. Each lab is stored in its own folder for easy navigation and clear project separation.

## Labs Included

- [lab-01](lab-01) - Basic Node.js server and HTTP routing tasks
- [lab-02](lab-02) - SQLite CRUD application with API endpoints
- [lab-03](lab-03) - REST API implementation, query filtering, validation, debugging practice, and deployment

## Lab 3 Overview

Lab 3 focuses on building and testing a REST API with Node.js and Express. It covers:

- CRUD operations for books
- Query parameters such as search, sort, pagination, and price ranges
- Input validation and error handling
- SQLite database integration
- API debugging and debugging practice exercises
- Deployment-ready project structure
